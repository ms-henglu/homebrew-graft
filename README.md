# Homebrew Tap for Graft

This is the official [Homebrew](https://brew.sh/) tap for [Graft](https://github.com/ms-henglu/graft) - The Overlay Engine for Terraform.

## Installation

```bash
brew tap ms-henglu/graft
brew install graft
```

Or install directly:

```bash
brew install ms-henglu/graft/graft
```

## Updating

```bash
brew update
brew upgrade graft
```

## What is Graft?

Graft is a tool for customizing Terraform modules without forking. It allows you to:

- Override values in Terraform modules
- Inject new resources and logic
- Remove attributes from modules
- Apply patches using a declarative manifest file

For more information, visit the [Graft repository](https://github.com/ms-henglu/graft).
